## Исправления при объединении

- Источник происхождения app_meta/ml_meta проверяется совместно; конфликт запрещён. Новая неизвестная БД не объявляется реальной автоматически.
- Скидка не учитывается дважды: оплаченная цена уже после скидки. Денежные расходы и диагностическая сумма скидок разделены.
- Для сценарного k используется `(k × R − C) / C`, а не умножение всего ROMI на k. k ограничен интервалом [0,1].
- Уникальная инвайт-ссылка другого канала не создаёт ложного источника. Несопоставленное вступление сохраняется с неизвестным источником.
- МЛ имеет отдельный API-раздел, использует тот же --db, не обучается в HTTP, возвращает агрегаты. Индивидуальные ID в операционном интерфейсе заменены псевдонимами.
- Старые исходники/документы с персональными сведениями и устаревший HTML не включены в публичный комплект. Исторические хеши не соединяются с новыми Telegram ID без таблицы соответствий.

## Граница готовности

Локальные тесты и запуск выполнены. Подключение к реальному Telegram и CRM, испытание МЛ на реальной аудитории, контрольный маркетинговый эксперимент и публичный GitHub не выполнены. HTML-снимок интерфейса отрендерен без полноценного браузера; проверены HTTP и JavaScript, но не браузерная визуальная совместимость.

Архивы старых этапов не являются исполняемыми частями новой сдачи. Их контрольные суммы и списки файлов сохранены в `sources_inventory.json` для прослеживаемости без публикации исходных клиентских данных.
