## Среда и воспроизводимость

Ядро и HTTP-импорт дополнительно запущены в новом `venv`, где был установлен только pip. Главный аналитический конвейер также выполнен в отдельном новом venv без сторонних пакетов. МЛ использует проверенный локально установленный набор: точные версии зафиксированы в ml/requirements.txt. Сетевая установка пакетов в чистый venv в данной среде не выполнялась; доступ к репозиторию пакетов ограничен.

На синтетике модель покупки использовала fit/calibration/test 780/120/180 наблюдений; модели каналов — 64/10/13. Несозревшие и пересекающие границы окна исключены. Линейная модель покупки и ExtraTrees для каналов выбраны по временной проверке. Метрики приведены в ml/README.md и ml/reports/audit.json; они не являются результатами на клиентах бизнеса.

Исторический реальный прогноз выбран по 11 перекрывающимся окнам, последняя неделя не использована для выбора. Ошибка недельной суммы 38,15% против 26,96% baseline. Реальные файлы покупателей и их строки не публикуются; команда воспроизведения требует CSV владельца.

## Непроверенные внешние сценарии

Боевые Telegram run/invite, CRM-расписание на внешнем сервере, реальные оплаты, реальное качество МЛ и причинный эксперимент не запускались. Команды для них в README — инструкции настройки, не свидетельства успешного боевого исполнения. Полноценный движок браузера недоступен; HTML-рендер для презентации не называется браузерным скриншотом. Windows-специфическая активация окружения приведена как стандартная инструкция, Windows в этом прогоне не использовалась.
